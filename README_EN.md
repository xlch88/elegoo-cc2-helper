# elegoo-cc2-helper

Code and notes from my experiments with the ELEGOO Centauri Carbon 2 (CC2): SSH, firmware differences, theme switching, and a buzzer notification program I wrote for the printer.

`elegoo-cc2-helper` is written in Go and plays different sounds when a print starts, pauses, resumes, is cancelled, or completes.

Author: [Dark495](https://github.com/xlch88)
