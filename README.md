# elegoo-cc2-helper

这里收集了我在使用和折腾 ELEGOO Centauri Carbon 2（CC2）过程中的一些个人研究成果，包括固件分析、SSH、界面主题，以及自己写的小工具。

其中，`elegoo-cc2-helper` 是一个用 Go 编写的蜂鸣器提示音程序，让打印机在开始、暂停、恢复、取消和完成打印时发出不同的声音。安装和使用方法见下面的文章。

把这些内容整理出来，一方面是给自己留份笔记，另一方面也希望给同样喜欢折腾 CC2 的朋友提供一点参考。欢迎交流，也欢迎指出文档中的错误。

作者：[Dark495](https://github.com/xlch88)
